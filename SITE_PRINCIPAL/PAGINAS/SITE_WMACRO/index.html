        Central de Ajuda

        1. Crie sua conta: Clique no ícone de perfil (canto inferior esquerdo) e em "Criar Conta". Preencha seu nome, e-mail e senha.

        2. Faça login: Use seu e-mail e senha, ou clique em "Entrar com Google" para autenticação instantânea.

        3. Explore: Após o login, todas as suas macros, variáveis e categorias ficam sincronizadas na nuvem automaticamente.

        Macros Criadas: Total de respostas rápidas salvas na sua conta.

        Cópias Realizadas: Quantas vezes você usou o botão "Copiar Resposta" no app.

        Categorias: Número de categorias criadas para organizar suas macros.

        Frequência de Uso: Gráfico de barras mostrando as macros mais acessadas.

        Nova Macro (card CTA): Atalho rápido para criar uma nova resposta sem ir ao menu lateral.

        Nome: Dê um nome descritivo — ex: "Saudação Comercial" ou "Link de Pagamento".

        Categoria: Selecione uma categoria existente (Suporte, Vendas, Pós-Venda) ou crie uma nova em Variáveis & Categorias.

        Descrição Breve: Resumo opcional para facilitar a busca.

        Conteúdo: Escreva o texto principal da macro no editor rico abaixo.

        Clique em "Salvar Resposta" para salvar na sua biblioteca.

        Barra de ferramentas: Negrito, Itálico, Sublinhado, Tachado, Cor de texto, Destaque, Alinhamento, Listas e Links.

        Desfazer / Refazer: Use os botões ↩ / ↪ ou os atalhos Ctrl+Z e Ctrl+Y.

        Inserir Imagem: Clique no ícone 🖼️ e selecione uma imagem do seu dispositivo.

        Inserir Emoji: Clique no ícone 😊 para abrir o seletor de emojis.

        Melhorar com IA: O botão ✨ usa o Gemini para reescrever e melhorar o texto selecionado. Configure a API Key em Configurações.

        Variável Fixa: Tem um valor padrão que você define — ex: "Nome do Cliente" com padrão "Cliente". Ao usar a macro, você pode substituir antes de copiar.

        Variável por Horário: O valor muda automaticamente de acordo com a hora atual. Ex: "saudacao" → "Bom dia" (00h–12h), "Boa tarde" (12h–18h), "Boa noite" (18h–24h).

        Inserir variável no editor: No painel lateral direito do editor, clique sobre o nome da variável para inseri-la no cursor. Ela aparece como uma pílula colorida.

        Criar variável pelo editor: Clique em "Nova Variável" na barra de ferramentas para criar sem sair do editor.

        1. Na lista "Minhas Macros", localize a macro desejada (use a busca ou filtro de categoria).

        2. Clique em "Usar" — abre a tela de preenchimento.

        3. Preencha os campos das variáveis (já mostram o valor padrão).

        4. Veja a Visualização ao vivo à direita com o texto final.

        5. Clique em "Copiar Resposta" — o texto é copiado para a área de transferência, pronto para colar no WhatsApp, e-mail, etc.

        Seu código de equipe: Um código único de 4 letras exibido no seu Perfil (ex: A3F9). Compartilhe com quem deseja ter acesso às suas macros.

        Adicionar membro: No Perfil, cole o código de 4 letras do colega e clique em "Adicionar". Ele aparecerá na aba Equipe.

        Ver macros de um membro: Na aba Equipe, clique no card de um membro para abrir a biblioteca de macros que ele compartilhou.

        Copiar macro da equipe: Na biblioteca de macros de um membro, clique em "Copiar para Minha Biblioteca" para salvar uma cópia nas suas macros.

        Compartilhar suas macros: No Perfil, na seção "Macros Compartilhadas", ative o toggle ao lado de cada macro que deseja liberar para sua equipe ver.

        Integração Gemini AI: Insira sua chave de API gratuita do Google Gemini para usar o recurso "Melhorar com IA" no editor.

        Exportar Backup: Baixa um arquivo JSON com todas as suas macros, variáveis e categorias para backup local.

        Importar Backup: Restaura os dados a partir de um arquivo JSON exportado anteriormente.

        Redefinir Dados: Apaga todos os dados e volta aos exemplos padrão. Esta ação não pode ser desfeita.

        Tema: Alterne entre modo claro e escuro no botão ☀️/🌙 no canto inferior da barra lateral.
